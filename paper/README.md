# Workshop paper draft

The main LaTeX file is a two-column, template-neutral draft. It currently reports only the frozen V1 diagnostic findings. V2, final-test, controlled-RL, and cross-task claims remain absent until their prediction and receipt files are audited.

Regenerate the V1 figures and table from saved machine-readable predictions by running the paper-asset generator from the repository root. The asset-sources JSON file records source hashes. Use the Codex built-in LaTeX editor/compiler for preview. The appendix is optional and is not automatically included in the four-page main draft.
