# V2 literature audit (source-checked 2026-09-30)

This is an overlap audit, not a novelty claim. The candidate contribution is a **within-model, causal-window analysis of structured robot failure critics**, separating interface compliance from task semantics and testing whether state-conditioned verifier reward changes a measured collapse. All result claims below are attributed to the cited papers; our own V2 claims require independent frozen evaluation.

| Work and venue | Question / method / data | Reported result | Relation and actual gap |
| --- | --- | --- | --- |
| [Ofori-Ampofo et al., REBOOT (2026)](https://arxiv.org/abs/2609.22591), arXiv preprint | Failure/recovery data for bimanual precision assembly; 2,160 demonstrations, 18 tasks, five shared phases, four RGB-D views. | Publishes phase/failure-annotated benchmark and policy phase-completion analysis. | Source benchmark, not a study of VLM post-training collapse. We must not present dataset design as ours. |
| [Navasardyan et al., FailBench (2026)](https://arxiv.org/abs/2609.03611), arXiv preprint | Cross-source VLM failure detection; 2,197 attempts across 14 sources, 13 detectors. | Fine-tuned failure detectors underperform general-purpose VLMs and their own pretrained bases; contact-intensive assembly falls below 0.60 balanced accuracy; targeted visual cropping helps by 2.4 points. | **Major overlap with H2 and observability.** We cannot claim first evidence of fine-tuning erasing failure detection. Our narrower possible contribution is temporal REBOOT state/phase diagnosis, strict-vs-semantic separation, paired checkpoint progression, and a controlled reward comparison if executed. |
| [Ajith et al., RoboMonitor (2026)](https://arxiv.org/abs/2609.30715), arXiv preprint | Label-efficient causal monitor, predictive representation pretraining plus Temporal SFT, four-task benchmark. | Reports 93.1% mean phase accuracy and 85.9% macro recall with 52 labeled episodes; Temporal SFT reduces spurious phase switching in a Qwen3-VL ablation. | Important positive counterexample: temporal SFT *can* improve monitoring. Our negative or mixed result would be setting- and recipe-specific, not a universal SFT failure. |
| [Agia et al., Sentinel (2024)](https://arxiv.org/abs/2410.04640), CoRL 2024 | Runtime failure detection combines action-consistency statistics and VLM task-progress checks in diffusion-policy mobile manipulation. | Combined detectors find 18% more failures than either alone. | Motivates complementary observations and time-sensitive metrics. It is not a controlled SFT/GRPO reward study. |
| [Wang et al., LabRobFail (2026)](https://arxiv.org/abs/2607.23704), arXiv v2, under review | Failure detection/localization/recovery in chemical self-driving labs; >20,000 trajectories; domain-adapted VLM. | Current v2 abstract reports 90.83% failure-detection and 77.21% localization accuracy on seen environments, plus 4–16 point downstream gains. | Another positive specialized-training result; different domain, supervision, and evaluation. It prevents a broad claim that VLM specialization always harms awareness. |
| [Liang et al., Robometer (2026)](https://arxiv.org/abs/2603.02115), arXiv preprint | General-purpose robot reward modeling from within-trajectory progress and cross-trajectory preferences; RBM-1M. | Reports more generalizable reward functions and downstream robot-learning gains. | Progress/reward estimation is adjacent, but not a structured `nominal/failure/recovery` output or a parser-compliance analysis. |
| [Shao et al., DeepSeekMath (2024)](https://arxiv.org/abs/2402.03300), arXiv preprint | Introduces Group Relative Policy Optimization (GRPO) for mathematical reasoning. | Reports strong MATH performance and reduced PPO memory use. | Algorithmic source only. Its math results do not support robot-critic capability claims. |
| [Zheng et al., GSPO (2025)](https://arxiv.org/abs/2507.18071), arXiv preprint | Sequence-level importance ratio/clipping versus token-level GRPO. | Reports improved language-model RL stability/efficiency, especially MoE. | Defines the algorithmic distinction. We must not infer robot benefits from it; V1 GSPO is exploratory and V2 GSPO requires its own gate. |

The precise additive-component shortcut in our critic must be shown by measured rewards and paired outputs, not cited into existence. |

## Novelty boundary

FailBench already demonstrates a broad failure-detector fine-tuning regression. A defensible workshop contribution would therefore be **mechanism isolation**, not the general observation: (1) a frozen deterministic parser split that exposes a hidden Base signal, (2) causal, episode-disjoint state-only/camera/dense/trace comparisons, and (3) a same-checkpoint additive-versus-state-gated RL comparison **only if the validation gate opens**. If that gate remains closed, H3 is a reward-design hypothesis illustrated by V1 behavior, not a controlled causal finding.

## Evidence and citation cautions

- REBOOT's project page describes four RGB-D views and phase/failure annotation, but each hosted task must be checked for accessible machine-readable onset labels before cross-task scoring. A repository name or task description alone does not provide `failure_onset` or `recovery_onset` labels.
- FailBench focuses on task-success judgments, while our pilot predicts within-trajectory nominal/failure/recovery states. The overlap is still substantial and must be cited in the introduction.
- RoboMonitor's positive Temporal SFT result and LabRobFail's positive domain specialization mean any erasure claim must name the exact model, task, prompt, data, and split.
- An increase in training reward, JSON validity, or aggregate Macro-F1 is not evidence that Failure Recall improved. Strict JSON and semantic normalization are different endpoints.
