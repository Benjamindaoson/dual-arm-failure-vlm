# Reviewer attacks：先答证据，再承认边界

以下是投稿前检查表；V2 尚未出齐的项目明确标为待验证，不以计划代替结果。

1. **Base 的零分是否纯属解析器产物？** 严格协议下是零；机械去除整个输出的单层 fence 后 54/54 可解析、Failure Recall 为 6/18。严格指标不重写，语义指标标为回顾性诊断。
2. **Semantic normalization 是否事后挑选？** 规则确由 V1 错误分析触发，所以 V1 是 post-hoc 发现；规则、单测和排除项在所有 V2 GPU 新运行前冻结。不能宣称 V1 语义结果预注册。
3. **为何旧六个 episode 不作 final？** 它们已决定问题、方法和奖励设计；继续当未触碰测试会泄漏研究者选择。
4. **failure/recovery 是否从 RGB 可辨识？** 当前标签来自事件帧与阶段标注，不是独立的人类视觉可辨性测量。相机消融、时序延迟和 Trace 是间接诊断；视觉可辨性仍是局限。
5. **wrist 摄像头改善是否只是信息量多？** 每组均为两路相机、四时刻、相同像素预算和训练配置；仍不能把视角差异解释成唯一因果机制。
6. **dense windows 有未来泄漏吗？** 每窗断言 sampled_frame 不大于 anchor；episode 按组划分。边界样本可能改变类别频率，需单独报告。
7. **SFT 消失是否只是 class imbalance？** 目前不能排除。state-only、密集监督及预测分布可缩小解释范围；如没有类别平衡控制，论文不得称已排除。
8. **GRPO collapse 是否只是权重选择？** V1 只能提示风险。只有同起点、同预算的 additive/gated V2 对照及成对 held-out 结果才能检验。
9. **gated reward 是否人为偏向 failure？** 它明确把漏检作为代价，属于目标设计而非中性优化。应同时报误报、precision、balanced accuracy 和其他类 recall，防止“全报 failure”。
10. **为什么不用普通分类器？** 本研究诊断结构化 VLM Critic 的后训练行为，不证明 VLM 比最强分类器更优；分类器对照未运行则写 N/A。
11. **为什么需要 VLM？** 它可同时接受多视角、任务指令和可选 Trace 并输出结构化诊断；这不是其优于专用模型的实证结论。
12. **跨任务了吗？** 官方任务 ID 已核实，但远端 Hugging Face 连接超时、可用盘不足以安全下载完整仓库，已检索的 episode metadata 未提供可直接评分的 onset 标签。若最终 Tier B，明确只报单任务。
13. **六 episode 的 CI 可信吗？** episode-bootstrap 比 frame-bootstrap 合适，但六个聚类单位仍给出宽且不稳定的区间；不作总体泛化保证。
14. **种子敏感性？** screening 仅 seed 42；最终最佳 SFT 预设 42/43/44。若某条件未重复，标明单种子。
15. **能推广到汽车制造吗？** 不可。REBOOT 是公开双臂装配研究数据，不含生产线传感器、节拍、质量追溯与真实安全验证。
16. **输出机器人动作吗？** 不输出；这是状态 Critic，恢复决策/控制性能 N/A。
17. **与普通 failure classification 有何区别？** 因果历史、正常/失败/恢复三态、阶段/模式多任务、onset 延迟和协议有效性都被分开测量；但仍是离线诊断，不是在线闭环。
18. **additive/gated 是否真正控制变量？** 两者须用同一 full-schema SFT checkpoint、数据、种子、相机、rollout 和更新预算；禁用 additive 动态类别加权。未运行则不能声称已控制。
19. **GSPO 必要吗？** 不必要。仅 gated GRPO 在 held-out 上有真实增益且不 collapse 才运行；V1 GSPO 是探索性负结果。
20. **负结果的价值？** 可划定协议、可观测性、监督和奖励的失败边界；前提是保留全部 run、预测、类别分布与限制，不能把不运行或未收敛包装成机制证明。
